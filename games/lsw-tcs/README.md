# LEGO Star Wars: The Complete Saga — PC

Use the [classic PC readers](../../formats/classic-pc/README.md): archive extraction (index version -3, files
found through a hash of the upper-case path), NU20 scenes and models to DDS/PNG and glTF, AN3 animation with
skeleton export, CU2 cutscenes and GIZ pickups.

Checked on the Steam release (app 32440): all 1,477 model and scene files, all 2,911 animations, all 205
cutscenes and 248 of 251 gizmo files decode (the other three are empty or cut off in the game data). This is
decode coverage, not in-game or visual validation; see [coverage](../../formats/classic-pc/docs/COVERAGE.md).

This is a different layout from the original 2005 game: for that, see [LSW1](../lsw1/README.md).
