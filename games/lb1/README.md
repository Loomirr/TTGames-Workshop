# LEGO Batman: The Videogame (2008) — PC

Use the [classic PC readers](../../formats/classic-pc/README.md): archive extraction (index version -2), NU20
scenes and models to DDS/PNG and glTF, AN3 animation with skeleton export, CU2 cutscenes, GIZ pickups and the
GIT puzzle logic.

Checked on the Steam release (app 21000): 939 of 940 model and scene files, all 2,578 animations, all 135
cutscenes and all 171 gizmo files decode. This is decode coverage, not in-game or visual validation; see
[coverage](../../formats/classic-pc/docs/COVERAGE.md).
