# LEGO DC Super-Villains — PC

[CU3 tools](../../formats/cu3/README.md) have partial structural and name-editing
support for observed files. The private research folder contains further probes.

The separate [DCSV archive-index GUI](../../builds/README.md#separate-gui-downloads)
0.1.5 inventories the verified CC4 archive layout. Its CLI supports
`--help` and refuses to replace existing reports. It does not extract models
or enable ANI-E playback.

Full character mesh reconstruction, ANI-E facial playback and faithful cutscene
assembly are not established. Do not infer support from LB3 or LMSH1 alone.

## Shader and facial completion

This edition must separately pass **1:1 shader matching, face reconstruction,
facial animation and native facial/material export**. These remain open goals;
see the [per-game checklist and required evidence](../../docs/VISUAL_AND_FACE_COVERAGE.md).
