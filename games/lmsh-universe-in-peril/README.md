# LEGO Marvel Super Heroes: Universe in Peril — Nintendo 3DS

The verified local USA CTR-P-AL5E build uses FUSE archive records and BTGA
textures with PICA tiled mip payloads. Native body atlases can be very small.

See [BTGA / FUSE tools and notes](../../formats/btga/3ds/README.md). The original
3DS atlases are not LOTDK atlases. Upscaling and print tracing live in the local
archive and do not recover missing original detail or generate new artwork.
