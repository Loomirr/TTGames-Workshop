# LEGO Indiana Jones: The Original Adventures (2008) — PC

Use the [classic PC readers](../../formats/classic-pc/README.md): archive extraction (index version -2), NU20
scenes and models to DDS/PNG and glTF, AN3 animation with skeleton export, CU2 cutscenes, GIZ pickups and the
GIT puzzle logic.

Checked on the Steam release (app 32330): all 1,015 model and scene files, all 2,524 animations, all 112
cutscenes and all 103 gizmo files decode. This is decode coverage, not in-game or visual validation; see
[coverage](../../formats/classic-pc/docs/COVERAGE.md).

This is the retail PC game. The Xbox 360 prototype has its own entry: [LIJ1 prototype](../lij1-prototype/README.md).
