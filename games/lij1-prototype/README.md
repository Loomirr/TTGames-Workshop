# LEGO Indiana Jones 1 — Xbox 360 prototype

Use the [NU20 DDS extractor](../../formats/nu20/lij1-xbox360/README.md).
It accepts the observed big-endian prototype GHG/GSC texture descriptors and
untile/byte-swaps supported BC1 and BC3 textures with their original mip chains.
See that folder's FORMAT.md for bounds and layout restrictions.
