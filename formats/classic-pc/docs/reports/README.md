# Working reports

These are the working notes written while each reader was being fixed and measured (2026-10-08). They were
written by AI agents for the maintainer, so they speak of "the brief", "the previous agent" and scratch
scripts that are not in this repository. They are kept unedited, apart from machine paths, because they carry
the evidence behind each claim in `../COVERAGE.md` and `../FORMATS.md`: file counts, offsets, and what is
guessed against what is measured.

- `nu20.md`: scenes and models (`nu20.py`, `gltf_export.py`)
- `anim.md`: animation decoding and export (`an3.py`, `anim_export.py`)
- `cu2.md`: cutscenes (`cu2.py`)
- `giz.md`: gizmo files (`giz.py`)
- `lb2.md`: LEGO Batman 2's archives (index version -4) and what its files are
