# October 19 PR integration and issue review

Character 0.5.21, CU3 0.1.29 and Classic PC Inspectors 0.1.3 integrate PRs
12–16 and 18–26. The dependent LB2 changes were reviewed together. This adds
experimental LB2 character/animation import, observed older LB2/LMSH1 models,
classic rigid attachments and distinct duplicate bone labels, optional game
handedness, RGB surface normals and reflection-cubemap preview.

Integration fixes add the missing LB2 saved-folder preference, restrict LB2 BSA
reserved words and cross-joint LOD remaps to observed layouts, cap expanded
vertex-frame allocations, and store vertex-frame action keys in linear space.
Issue 27's observed HGOL 15 variant trailer is accepted without relaxing its
map, scale, fence or bounds checks. Other unknown layouts remain refused.

## Validation

Python 3.14.7 and Blender 5.2.2 LTS were used. Reproducible asset-free commands:

```text
python tools/check_repository.py
python tools/check_docs.py
blender --background --factory-startup --python-exit-code 1 --python tools/check_blender_packages.py
blender --background --factory-startup --python-exit-code 1 --python formats/cu3/scripts/test_vertex_frames_blender.py
```

The repository check includes the new LB2, LMSH1 display, cubemap and classic
bone-label regressions. Blender tests check extracted packages, simultaneous
registration, saved game-folder fields, file drops, authored normals, facial
render helpers, and every frame of an 80-frame vertex-animation fixture.
Original inputs and machine-specific logs stay local.

Complete character import/render checks passed for LB2 Batman, Joker and Mad
Hatter, LMSH1 Black Widow and Hulkbuster, and LB3 Batman. The rendered images
were inspected. LB2 Batman's 321-frame Idle and little-endian 21-frame WALK,
and Joker's 190-frame Idle import without reported errors; first, middle and
last poses are finite. Selected animated poses were rendered too. Joker's face
still shows overlapping surfaces, including during Idle, so this is not a
complete facial-shading fix. Hulkbuster's reflection preview is approximate.

The supplied TCS rigid-layer Blender check passed on local Yoda and Grievous
GHGs: 13 and 76 rigid pieces, none unbound, maximum posed-vertex error below
`6.1e-8`. These are from a modded installation. LB3 B66 Robin's handedness
check passed with byte-identical native exports before/after mirroring.

## Remaining PRs and issues

- PR 10 (LSW2 HGP importer/exporter) is held: the unchanged-part fast path
  ignores normal-only and color-only edits, and original-file identity is not
  hash-bound. A synthetic normal-only change reproduced the fast-path bug.
  It needs guarded export regressions before publication.
- PR 17 (TCS runtime patch) is held: `write_mem` ignores memory-protection
  failures and the executable check dereferences fixed addresses before
  validating mapped image bounds. Runtime/build validation remains outstanding.
- Issue 1 has targeted normal/reflection/handedness improvements, but blink
  occlusion and native shading are not fully resolved.
- Issue 9 has substantial LB2 model/animation improvements; LB2 CU3 scene
  decoding and older texture/geometry layouts remain incomplete.
- Issue 11 remains runtime-behavior research, not an importer fix.
- Issue 27 is partially addressed; the malformed/unverified files above remain
  refused. Successful decoding alone is not proof of complete facial fidelity.

No in-game tests or game-file changes were made during this review. LB2 source
export and complete LB2 cutscenes are not enabled. The contributor's detailed
LB2 research documents retain their historical measurements; the table above
records the independent combined-build sample from this pass.
